Selected public projects in research, software, and open learning resources.

  • RFMeasurement: open-source Python framework for uncertainty-aware validation and reproducible RF measurement analysis. Documentation.
  • PreMoCir: machine-learning project for predicting mortality after cardiac surgery.
  • adsblib: portable C99 library for encoding ADS-B Out DF17 messages. Project site.
  • NanoVNA Measurement Course: open learning module on S-parameter measurement and calibration. Course materials.
  • Math Tools for Biomedical Electronics: open computational module applying complex numbers, matrices, and calculus to biomedical circuit analysis. Demo.
  • From Code Repository to Research Infrastructure: research design and materials for a study of GitHub across the scientific research lifecycle.
  • GitHub–Zenodo–ORCID Reproducibility Workflow: materials for evaluating traceability and reproducibility in research workflows.

More public projects are available on GitHub.
